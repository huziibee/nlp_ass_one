# Original Omniglot experiments — permanent source-linked archive

This folder contains actual downloaded nonbinary GitHub Actions results from the original Base/Extended G10, eight-arm curves, free-symbol distribution, causal head interventions, six repair conditions, Extended independent replicates and historical G3 frozen test. **Nothing in this folder should be interpreted as a newly performed independent final test.**

See `EVIDENCE_MANIFEST.json` for source run ID, relative filename, size and SHA-256. Binary model checkpoints stay in the original Actions artifacts and may expire. The original G3 protected test has been used and must not be used for new G10 selection.
